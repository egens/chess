# Piece set: cburnett

SVG chess pieces by Colin M.L. Burnett (https://en.wikipedia.org/wiki/User:Cburnett),
the set used by Wikipedia and lichess.org. Copied from the `@lichess-org/chessground` package.

License: GPLv2+ (also available under BSD and GFDL, see
https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces).

At runtime the black pieces are recolored to dark grey (`js/art.js`).
