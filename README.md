# Воксельные шахматы

Браузерные шахматы с воксельной графикой на Three.js. При взятии фигура разваливается на кубики,
которые разлетаются по доске, отскакивают и исчезают.

**Играть:** https://egens.github.io/chess/

## Возможности

- Полные правила: рокировка, взятие на проходе, превращение пешки (с выбором фигуры), мат, пат,
  правило 50 ходов, троекратное повторение, недостаточный материал.
- Игра против компьютера за белых или за чёрных, либо вдвоём на одном устройстве.
- Компьютер: alpha-beta с итеративным углублением и quiescence-поиском, 4 уровня силы.
  Считает в Web Worker, интерфейс не подвисает.
- Отмена хода, поворот доски, запись партии в нотации SAN, синтезированные звуки.
- Вращение камеры мышью/пальцем, работает на телефоне.

## Запуск локально

Нужен любой статический сервер (ES-модули не работают через `file://`):

```sh
npm start          # python3 -m http.server 8000
# открыть http://localhost:8000
npm test           # perft-тесты генератора ходов и проверка ИИ
```

Сборки нет: Three.js r160 лежит в `vendor/`, всё остальное — чистый JS.

## Структура

| Файл | Что внутри |
|---|---|
| `js/chess.js` | Правила: генерация ходов, make/undo, статус партии, SAN |
| `js/ai.js` | Поиск хода (работает в Web Worker) |
| `js/voxels.js` | Воксельные модели фигур и доски, мешер с отсечением скрытых граней |
| `js/main.js` | Сцена, ввод, анимации ходов, физика обломков |
| `js/sound.js` | Звуки через Web Audio |
