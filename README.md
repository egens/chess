# Воксельные шахматы

Браузерные шахматы с воксельной графикой на Three.js.

**Играть:** https://egens.github.io/chess/ · **v1** (3D-доска со свободной камерой): https://egens.github.io/chess/v1/

## v2

- Камера зафиксирована сверху, фигуры классической формы, их легко узнать сверху.
- Ход можно сделать перетаскиванием фигуры или двумя кликами. Если отпустить фигуру на недопустимой клетке, она вернётся на место.
- При взятии фигура разваливается на кубики, а фигура, которая её взяла, загорается.
  Огонь растёт с каждым следующим взятием и переходит к фигуре, в которую превратилась пешка.
- Онлайн-игра через [Lichess](https://lichess.org) (Board API): вход через OAuth (PKCE, без регистрации
  приложения), поиск соперника, вызов игрока по нику, входящие вызовы, часы, ничья, сдача.
  Board API допускает только партии от рапида, поэтому есть контроли 10+0 … 30+20.
  Незавершённая партия на Lichess подхватывается автоматически.
- Режимы: игра против компьютера за белых или за чёрных (4 уровня силы), вдвоём на одном устройстве или онлайн.
- Полные правила, отмена хода, поворот доски, запись партии, звуки.

### Внешний вид

Фигурки собраны из вокселей по силуэтам 2D-наборов фигур и имеют объём. Наборов два: классический
(cburnett) и Staunty с lichess, переключаются в панели.
Доска тоже воксельная: цвета классические сине-белые, рамки нет, координаты нарисованы внутри крайних клеток.

### Игровые удобства

- **Огонь** можно выключить галочкой в панели.
- **Оживление**: фигуры чуть «дышат», а раз в несколько секунд одна случайная фигура делает короткое
  движение: пешка подпрыгивает, конь вертит головой, слон делает пируэт, ладья притопывает,
  ферзь приосанивается, король оглядывается. Отключается галочкой «Оживление».
- **Часы**: в локальной игре можно включить контроль времени (1+0 … 15+10), в онлайне идут часы lichess.
  Над доской и под ней полоски показывают оставшееся время: сверху соперник, снизу вы.
  У кого вышло время, тот проиграл (если у соперника хватает материала для мата).
- **История ходов**: кнопки ⏮ ◀ ▶ ⏭, стрелки ← → (Home/End) или клик по ходу в записи.
  Любой клик по доске или новый ход возвращает к текущей позиции.
- **Премув**, как на lichess: пока ходит соперник, можно заранее задать один ход. Он сыграется сразу,
  если будет допустим; превращение пешки при этом всегда в ферзя. Клик мимо отменяет премув.

Все настройки (фигуры, огонь, оживление, часы) запоминаются в браузере.

## Версии

- `v1` — ветка с первой версией (3D, свободная камера). Workflow публикует её в `/v1/`.
- `main` — текущая версия, публикуется в корень сайта.

## Запуск локально

Нужен любой статический сервер (ES-модули не работают через `file://`):

```sh
npm start          # python3 -m http.server 8000
# открыть http://localhost:8000
npm test           # perft-тесты генератора ходов и проверка ИИ
```

Сборки нет: Three.js r160 лежит в `vendor/`, всё остальное — чистый JS.
Вход в Lichess работает и с `localhost`: адрес возврата берётся из текущей страницы.

## Структура

| Файл | Что внутри |
|---|---|
| `js/chess.js` | Правила: генерация ходов, make/undo, статус партии, SAN |
| `js/ai.js` | Поиск хода (работает в Web Worker) |
| `js/voxels.js` | Воксельные модели фигур и доски, мешер с отсечением скрытых граней |
| `js/main.js` | Сцена, камера, ввод (клики и перетаскивание), анимации, обломки, онлайн-режим |
| `js/art.js` | Загрузка SVG-фигур и их перевод в сетку для воксельных фигурок |
| `assets/pieces/` | SVG-фигуры cburnett и staunty (лицензии: см. README внутри) |
| `js/fire.js` | Воксельный огонь на фигурах, которые брали |
| `js/idle.js` | Оживление: «дыхание» и короткие движения фигур в покое |
| `js/burn.js` | Сколько взятий у каждой фигуры (для силы огня) |
| `js/lichess.js` | Клиент Lichess: OAuth PKCE, NDJSON-потоки, Board API |
| `js/sound.js` | Звуки через Web Audio |

## Деплой

Workflow `.github/workflows/pages.yml` гоняет тесты и публикует сайт (`main` в корень, ветку `v1` в `/v1/`) при пуше в `main`.
В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
